# 簡報示例：「Make it move」循環

你對 Claude 說的話：
> 幫我做個動態圖形。16:9，9 秒，swiss-grid，要循環，文字 "Make it move."，其餘用風格預設值。

Claude 據此寫出的簡報（技巧 3：每個形容詞都變成數字）：

- 畫幅：1920 x 1080，9.0 秒，30 fps，循環（9.0 秒處的幀 = 0 秒處的幀）。
- 風格：swiss-grid。底色 #FFFFFF，墨色 #111111，網格 #E6E6E6，強調色 #E4002B。Inter 900，字距 -0.04em。
- 緩動：文字落定用 expo.out 0.6 秒，離開用 power3.in 0.35 秒，方塊移動用 power3.inOut 0.5 秒。
- 文字："Make" / "it" / "move." 豎向堆疊，靠左邊距對齊。最後一個詞會替換：move. -> loop. -> land.
- 唯一的視覺母題：紅色句點。它在詞與詞之間跳躍，落下時被壓扁。
- 節拍表：
  | 時間 | 畫面內容 | 主動作 |
  |---|---|---|
  | 0.5 | 右側 3 x 3 方塊陣，留一個空位 | 一個方塊滑進空位 |
  | 1.5 | 最後一個詞向上滑出遮罩，新詞向上滑入 | 紅點跳起並落下 |
  | 2.5、3.5 | 方塊繼續滑動，空位繞一圈移動 | 方塊移動 |
  | 4.5 | 第二次換詞 | 紅點跳躍 |
  | 5.5、6.5 | 方塊 | 方塊移動 |
  | 7.5 | 第三次換詞，回到 "move." | 紅點跳躍 |
  | 8.5 | 最後一次方塊移動，讓空位走完一圈 | 此時畫面等於第 0 幀 |
- 停用：漸變、陰影、發光、圓角、居中文字、第二種強調色、運動物體上的線性緩動。
- 檢查：loop_check.py（0 秒與 9 秒必須一致），pacing_check.py（沒有超過 1 秒的空檔，沒有短於 0.3 秒的停留）。

按這份簡報做出的成品是 `styles/swiss-grid/index.html`（它在風格畫廊裡的影片是 `gallery/videos/swiss-grid.mp4`）。
