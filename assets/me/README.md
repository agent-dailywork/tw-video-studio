# 你的預設素材

需要人物、而你這次沒給別的素材時，Claude 會用這個資料夾裡的檔案。全部都是選填，有什麼放什麼。
檔案預設**不會**被推上 git（見 `.gitignore`），只留在你自己的電腦上。

| 檔名 | 內容 | 建議規格 |
|---|---|---|
| `p1.png`–`p5.png` | 去背人像（透明底 PNG）。p1 正面站姿、p2 坐姿、p3 倚靠、p4 單手插袋正面、p5 側身回頭（姿勢可以自己定，改下方說明即可） | 直式，長邊 2000px 左右 |
| `photo1.jpg`–`photo5.jpg` | 上面 5 張的原圖（乾淨單色背景最好） | 同上 |
| `webcam.mp4` | 你對鏡頭講話的口播片段，有原聲，已剪掉口誤 | 4:5 或 9:16，15 到 30 秒 |
| `ai-walk.mp4` | 走向鏡頭的片段（可以用 fal.ai 從你的照片生成） | 16:9，5 秒左右 |
| `ai-turn.mp4` | 從側身轉向鏡頭的片段（同上） | 16:9，5 秒左右 |

去背可以讓 Claude 在本機用 `rembg` 幫你做。
