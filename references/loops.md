# 把作品做成循環

只有結尾那一幀和開頭那一幀完全相同，循環才是無縫的。
`styles/` 裡大多數標註「不循環」的參考作品，都可以按這份清單改成循環。

## 清單
1. **沒有入場。** 第 0 幀必須是一幅完成的、好看的畫面，而不是一張等著元素飛進來的空頁面。
   把入場構建挪到後面，或者讓時鐘從某段停留的中間開始。
2. **一個時鐘。** 所有東西都根據 `t` 繪製（`STUDIO.play(render, { loop: true })`）。不讀取任何真即時間。
3. **整數週期。** 每個波動、搖擺、上下浮動、旋轉或漂移，都必須在整個時長內走完整數個週期：
   `Math.sin(2 * Math.PI * n * t / D)`，其中 `n` 為整數。用
   `grep -n "t \*\|Math.sin(t\|Math.cos(t" index.html` 找出違規寫法。像 `x = t * speed` 這樣的漂移，要改成搖擺或迴繞。
4. **有去有回。** 每個一次性變化（變色、變形、縮放、計數）到結尾都必須回到起始值。
   把單向曲線改成先升後降的起伏，並在動作結束時精確吸附到終點值。
5. **噪點要回繞。** 用幀序號驅動的顆粒、閃爍或粒子幀必須迴繞：`frame % totalFrames`。
6. **在看不見時重置。** 如果某樣東西必須跳回原位（一朵雲、一個計數器），就在它出畫或被遮住時跳。
7. **接縫處保持運動。** 循環點前後應該有大的東西在動，這樣永遠不會感覺停頓。
   執行 `pacing_check.py --loop`，它也會測量跨接縫的空檔。

## 證明它
`python3 scripts/loop_check.py out/draft.mp4 --project proj`
- 測試 A：畫出 0 秒處和結尾處的幀（關閉單一時鐘的迴繞），逐像素比較。
- 測試 B：檢查從最後一幀跳回第一幀的變化不大於正常的一幀步進。
兩項都必須顯示 PASS。
